# AI Voice Assistant (Alexa Clone)

A Python-based AI voice assistant that can interact via voice commands, perform web searches, tell jokes, play music, calculate expressions, open applications, and more. This project demonstrates a personal assistant similar to Alexa using **speech recognition** and **text-to-speech**.

---

## Features

- **Voice recognition** using `SpeechRecognition` library.
- **Text-to-speech** using `pyttsx3` (supports male and female voices).
- Open websites like **Google**, **YouTube**, **Facebook**, **LinkedIn**.
- Play songs from a **custom music library**.
- Tell **jokes** using a separate jokes module.
- Provide **current time** and **date**.
- Perform **simple calculations** using voice commands.
- Open system applications like **Notepad**.
- Handles unrecognized commands gracefully.
- Runs in a **non-blocking, multithreaded** way for smooth speech output.
